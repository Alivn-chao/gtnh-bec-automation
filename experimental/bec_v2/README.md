# BEC V2 独立测试版

支持选择1至16台传送节点、按设备扫描序号或地址前缀绑定，以及每组多台纠缠器。已有稳定版无需替换。所有V2程序、配置、生产日志、蜂群日志都在 `/home/bec_v2/`；已转换的配方记录目录只读使用。

## 同配方物理并行

同一个BEC网络/装配机的节点归为一组，共用约束场、原液子网、韦门、蜂群收容仓和纠缠器。程序汇总这一组已接到的同配方批次，按各节点实际并行和已消耗量补液，确认过滤与蜂群后把全部参与节点同时放行。不是依次运行一台机器。

先完成的节点重新暂停，等整组完成后再开始下一轮；暂时不同配方或尚未接单的节点留在暂停队列。同配方识别依据每份凝聚物需求和蜂群等级；API未提供产物配方ID，使用者仍须向同组下发相同配方。运行中变更需求/等级会暂停核对。蜂群数量是共享读数，不把每个节点的共享蜂群数量重复相加。

多台纠缠器在组内一起启停，各台均回读确认，转换完成须等本组所有纠缠器停止活动。独立生产组可同时生产；共享主网供液接口的配置/搬液由互斥锁串行管理。本测试版只准备当前参与批次的总需求，不重复把同一AE订单总量乘以节点数。

## 安装与测试

把本目录的 `main.lua`、`lib/` 和 `runtime/` 原样放到游戏电脑 `/home/bec_v2/`。无需覆盖 `/home/bec_auto.lua` 或稳定版UI。`paste/` 是逐个文件的紧凑粘贴版，每个文件不超过257行；创建相应子目录后用 `edit` 粘贴，Ctrl+S保存、Ctrl+W退出。仓库若为私有仓库，游戏内匿名wget无法直接下载，使用登录GitHub后的下载包或粘贴版。

```sh
mkdir /home/bec_v2
mkdir /home/bec_v2/lib
mkdir /home/bec_v2/runtime
lua /home/bec_v2/main.lua setup
lua /home/bec_v2/main.lua monitor
```

向导先选节点数量和设备组数量，再绑定组内设备与各节点。方向提示与角色说明见 [配置示例](config.example.lua)。先看只读监控确认设备；配置向导与监控不写机器。运行前退出稳定版控制服务，确保所有节点暂停信号15、所有纠缠器已关闭且不活动，再启动：

```sh
lua /home/bec_v2/main.lua run
```

生产界面方向键选节点，`P`暂停所选节点整组，`R`核对现场后恢复整组，`A`暂停全部，`N`库存翻页，`Q`暂停全部并退出。蜂群切换暂停整组操作；收容总线子网只暴露蜂群仓，备用网与收容网独立，使用已有ME接口接法。每个节点需要读状态/需求/消耗的适配器；红石I/O只负责暂停，不能代替状态适配器。红石输出线路不可重复绑定。

停止时保留日志、已有库存和约束场。重启发现旧进度先等待核对；`R`只允许进入恢复检查，不跳过未确认搬液/下单/蜂群操作的禁止重放检查。生产过程中不要改绑定配置。

## 范围与验证

这是多节点独立试验版，黑色仪表盘显示各节点状态、并行、共享蜂群、纠缠器运行台数和凝聚物库存条。GPU有VRAM时使用缓冲区整帧提交。当前库存目标为参考线；后台固定目标预缓存、样板处理和可编辑缓存页仍由稳定版提供，V2暂不调用这些稳定版服务，避免两套控制器争抢机器。

`tests/test_v2.py` 用Lua 5.2模拟验证配置边界、同配方组队、并发放行、流体需求汇总、组内暂停、多纠缠器、异常和恢复约束。模拟通过不代表游戏硬件验收。建议先在1台节点测试，再扩2台同配方节点，确认同时运行与耗料后扩到16台。

运行核心来源于用户提供的2026-10-09服务器程序快照，并保留原液申请/搬运日志与过滤回读检查；蜂群模块来源于独立切换交付。稳定版及服务器存档不随本版本改写。
