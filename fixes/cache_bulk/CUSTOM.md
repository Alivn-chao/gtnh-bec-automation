# 单项缓存与鼠标设置

正常 Q 停止生产服务后安装 `patch_custom.lua`，再运行 `lua /home/bec_ui.lua run`，进入 C 缓存设置。
安装器支持已装配方优先 V1 或快速补库 V2 的实际上传版本，并自动包含 V2 修正。
所有修改先定位、编译，再写临时文件并回读；保留唯一备份，替换失败整体恢复。

- 左键点击流体行，直接输入新的整数目标（mB），点“保存”或 Enter。
- 单项目标 0：不再自动补此类型；保留已有库存，生产配方按实际需要备料。
- 点“取消”或 Esc：放弃此次编辑。
- 右键点击流体行，或编辑时点“恢复统一”：删除单项设置，使用默认目标。
- E 修改默认目标，已设置的单项目标保持；N 翻页。

配置仍在 `/home/bec_cache.config`，兼容旧 `{version=1,target=...}`，新增
`overrides={entangled_chromaticglass=30000,entangled_transcendentmetal=0}`。
键为登记凝聚物名称，值为 0 到 2147483647 的整数。默认目标仍须大于 0。
保存显式 flush、回读并保留旧配置备份。重启继续使用。

目标修改在新补库批次读取；已在途的请求、已搬液和未完成日志仍按原记录处理。
不会因调低目标倒出或删除场内凝聚物；整批转换可能略超目标。
库存展示保留 2 秒缓存、登记名称 60 秒缓存，R 可显式刷新。

`build_custom.py` 生成补库脚本和定位安装器。
`test_custom.py <真实快照home目录>` 使用 Lua 5.2 模拟运行实际上传 UI，验证
两种升级入口、安装回滚与重试、日志不改、流水控制器保留、鼠标保存/取消/右键恢复、
配置重载、默认目标与单项覆盖、0 不提交补库。模拟结果不代表游戏实机验收。
