# 现有单节点服务：高速口专用缓存修正

本文件用于作者已接好高速口的现有 `/home/bec_cache.lua`，来源为2026-10-09实际服务器程序快照。含该存档原有组件地址；不是V2安装器的通用缓存功能。其他存档不要直接照抄这些地址。

## 行为

- 自动扫描高速转运器，从接口暴露的流体名称识别路线；来源容量2147483647、接收接口6槽及16000容量的校验沿用原程序。
- 源口保留流体类型、库存为零时仍能识别路线；库存不足与路线识别分开判断。
- 后台每轮选择一种库存不足的凝聚物，按统一目标的剩余缺口补齐，取消约16桶的后台轮次限制。已有15984、目标144000时，本轮按128016 mB缺口准备。
- 只通过高速转运器搬液；普通流体接口不再作为供液回退路线。主网ME接口仍用于查询库存和申请AE合成，不代表从其普通缓存槽搬液。
- 有原液先搬，无库存缺口再申请AE合成；没有可合成配方时明确报错并保留现场。
- 已经接到生产订单时不启动新的缓存批次；正在执行的缓存申请仍先核对收尾，不强行取消并重复下单。完成后再轮到其他流体。
- 原来的未完成小批缓存先按旧日志目标收尾，下一轮才使用新批量。已搬原液、库存、配置与日志保留。

## 替换

先让正在执行的缓存批次正常完成，在缓存页Q回生产页，再在生产页Q正常暂停退出。只替换缓存脚本：

```sh
mv /home/bec_cache.lua /home/bec_cache.before_bulk.lua
wget -f https://raw.githubusercontent.com/Alivn-chao/gtnh-bec-automation/main/fixes/cache_bulk/bec_cache.lua /home/bec_cache.lua
lua /home/bec_ui.lua resume
```

若备份名已存在，换一个备份名。没有互联网卡时 `edit /home/bec_cache.lua`，粘贴同目录 `bec_cache.lua` 全文（不到257行），Ctrl+S保存、Ctrl+W退出，然后启动原生产UI。

不删除 `/home/bec_cache.journal`、`/home/bec_auto.journal`、缓存配置或配方记录。请求/搬运未确认时程序仍会拒绝重放，不能通过删日志绕过。
