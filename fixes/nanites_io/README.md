## 游戏端设置

- 两端都装1张红石卡、2张超光速卡，设“有红石信号时工作”。不使用常开或无信号工作。
- 南口“存储盘→网络”，建议“清空后移出”；北口“网络→存储盘”，“工序完成后移出”，不能等数字奇点装满。
- 两端只连接蜂群收容子网，该子网通过存储总线暴露蜂群仓；不能另连主网、备用大库或其他可存物品的位置。
- 保持传送节点 isWorkAllowed=false，暂停控制红石15；约束场保持开启。别运行生产UI或旧蜂群测试脚本。
