# 慢配方不再按库存变化超时

去掉连续生产阶段“凝聚物库存600秒不变就停止”的条件，正常配方允许持续运行直到完成、用户暂停、配方改变或设备故障。保留节点状态、配方/消耗核对、韦门、补料，以及搬盘/搬液等待保护。

`patch.py` 使用明确的旧代码片段作校验，生成仓库控制器和当前实际OC兼容控制器。`files/runtime/controller.lua` 是本轮从实际OC导出后仅应用上述补丁的完整文件，保留实机其它改动。

验证：`python fixes/slow_recipe/test_slow_recipe.py`。仓库版和实机版均模拟两小时无库存变化后完成、手动暂停、设备故障。另跑V3回归146项和20个核心场景通过；模拟时长不代表实机已经持续运行两小时。
