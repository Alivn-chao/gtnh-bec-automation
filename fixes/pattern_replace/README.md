# 新版 NEI 样板与单槽覆盖登记

网页“样板处理”中选择覆盖槽位（1–9），点击“备份并覆盖此槽”。放入完整 BEC
加工样板的副本，保留所有流体需求；覆盖只处理该槽位，不处理其他槽。

兼容两种格式：旧版 `entangled_*` 输入直接保存；新版 NEI 的 BEC 原液输入按明确
映射保存为凝聚物需求，mB 数量不变，再从加工样板中移除流体输入。支持现有控制器
使用的 19 种 BEC 原液及时间/空间、`fluid.` 别名。未知原液拒绝处理，保留样板。
不把原液当作普通物品，也不从已删流体的样板猜测需求。

例如本次新版样板包含 `molten.hypogen 576`、`molten.infinity 18432`、
`molten.celestialtungsten 294912`、`molten.neutronium 294912`，登记对应
`entangled_hypogen`、`entangled_infinity`、`entangled_celestialtungsten`、
`entangled_neutronium` 的相同数量。普通物品输入保留原样，包括新版的基岩超致密板。

覆盖前必须暂停并结束旧批次，关闭节点接单，确认没有未完成或未确认的生产/缓存
操作。仅能覆盖状态为 `converted` 的旧登记。旧文件保存在同目录 `.backup-N`，
新登记先持久化为 `prepared`，转换及回读通过才标记 `converted`。清除途中失败时
核对并还原当前完整原样板；还原成功后恢复旧登记，失败记录及备份继续保留。
未完成的旧转换不通过“覆盖”绕过。普通“处理一次”仍拒绝悄悄替换不同的旧登记。

完成覆盖后，把工坊中转换好的样板替换到实际投料接口。版本更新前的 AE 任务和
旧原料不会因此自动改成新配方；确认收回旧料，使用新样板重新下单。空原料盘需
放回左侧缓存驱动器，再启动自动化。
