# 从 OC 识别并选择真实机器地址

地址输入框旁新增「从 OC 识别 / 选择」，按模块用途筛选当前 OC 组件网络实际可见的设备。选择一项会把完整地址直接填入草稿并走原有确认保存流程，无需从截图转写，也不把分析器最后复制的地址当作目标地址。候选会显示已填在什么位置；相同设备不会按 UUID 排序猜物理位置。

## 单个设备和相同类型多台设备

1. 保持自动化暂停，选择模型模块，再点击相应地址框旁「从 OC 识别 / 选择」。节点地址、暂停红石、独立韦门分别选择。
2. 只有一个候选时，确认用途后选中即可。多个同类候选时，地址列表本身不能判定从近到远的位置。
3. 对多台同类设备，只断开目标适配器的 OC 信号分支（保留适配器和机器，不断整条公共主线），扫描一次作为基准。接回原线后点「重新扫描」，列表会优先显示「新增 / 重新接入」项。
4. 只新增一个匹配项时即可识别目标；如果新增多项，说明这个分支不只连接一台匹配组件，需要进一步缩小分支，不能随便选第一项。节点与红石的物理配对、输出方向仍按实物填写。
5. 组件为零时当前 OC 看不到目标：检查连接/适配器/P2P。扫描没有修改机器、红石、库存、配方或工作许可。

扫描每步最多四个组件，最多2048个网络组件/512个匹配项，每页六项；只读方法表，机器名只调用固定 getName；方法标记为false仍表示存在。前后差异仅保留本次网页会话，关闭重开后需重新建立基准。配置失败消息现在带设备组、纠缠器编号和完整地址。
