# 网页处理样板

顶部新增「样板处理」，提供只读预览、处理一次、停止处理，显示工坊地址、配方目录、1–9槽结果和错误。不需要退出网页执行 patterns 命令。

先绑定独立「样板工坊 ME 接口」并应用绑定；不得使用主网供液接口或原液子网接口。将原加工样板的副本放进该工坊接口。暂停自动化和纠缠器后，在弹窗里先预览，再处理一次。

预览不修改样板和需求记录。处理一次沿用已有转换事务：先保存原始需求、逐项去掉凝聚物输入、回读核对并记录 converted；失败保留记录并尝试按原内容还原，不覆盖已被换掉的样板。已转换且记录一致的项不会重复处理。停止/Q退出在槽位事务边界生效，已完成的转换和需求记录保留；关闭弹窗不取消任务，可重新打开查看。网页处理期间禁止编辑绑定或启动生产；每个槽位前重新检查节点/纠缠器状态、配置和剩余空间。
