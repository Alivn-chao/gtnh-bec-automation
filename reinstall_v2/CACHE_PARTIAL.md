## 安装与本次收尾

先在OC按Q退出旧网页。下载并安装：

```sh
wget -f https://fastly.jsdelivr.net/gh/Alivn-chao/gtnh-bec-automation@bec-v2-cache-partial-2026-10-17-r2/reinstall_v2/update_cache_partial.lua /home/bec_cache_partial_update.lua
lua /home/bec_cache_partial_update.lua
```

本次用户已明确确认原空间流体AE任务完成并从CPU消失。日志前序确认1,498,176，最后请求31,680、明确返回24,096；实物截图1,522,272，等于10,571×144+48。因此只补96，收尾1,522,368原液。原AE申请2,533,440与最后31,680均不会重发。

```sh
lua /home/bec_v2/cache_recover.lua run ae-finished
```

工具在任何硬件写入前，检查绑定、整组暂停且关闭接单、纠缠器停机、生产记录已收尾、原日志回执完整、独立子网实物精确一致、接收口空、约束场开启。原日志逐字保存为同目录`cache.journal.before-partial-recovery-N`并回读验证，然后才写恢复意图、补96、核对实物、转换并停止纠缠器。主网必须有这96原液，工具不会申请或取消AE任务。只读预览可使用`lua /home/bec_v2/cache_recover.lua preview`。

显示“缓存收尾核对完成”后：

```sh

```

原缓存目标和启用设置保留。重新打开网页后可处理样板或继续自动化。核对失败会保留记录；不要删除日志或盲目重跑。工具严格限定这类单种空间流体旧部分返回，拒绝未知结果及重复执行；不是通用清状态工具。

## 后续正常补库

明确成功、有效整数的部分返回按实际量入账，再核对子网精确增量。零返回须确认库存没变才继续等待，仍有进展超时。生产订单到来时仅补齐已搬入的不足一批部分再转换让位。false、nil、异常、非法数量、回执与实物不一致仍保留pending并停止，不猜测重放。
